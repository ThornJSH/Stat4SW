Stat4SW 사용 안내

버전 · 구글 시트 + Apps Script 통계 분석 도구

시작하기

  1. 데이터 입력: 데이터 탭 1행에 변수명, 2행부터 응답을 붙여 넣습니다. 탭이 없으면 메뉴 Stat4SW 통계분석 > 새 작업 시작 (데이터 모두 지우기)를 누르세요. 탭이 없으면 바로 만들어지고(실수로 지웠을 때도 같습니다), 이미 내용이 있으면 지워지므로 안내 뒤에 지우기를 직접 입력해야 진행합니다. (이미 내용이 있으면 모두 지우고 빈 템플릿으로 다시 만듭니다. 지울 내용을 안내하는 확인창이 뜹니다. 이 도구에는 되돌리기가 없으니 필요하면 먼저 시트를 복사하세요. 실수로 지웠다면 파일 > 버전 기록 > 버전 기록 보기에서 이전 시점으로 되돌릴 수 있습니다.)
  2. 변수 설명(선택): 메뉴 Stat4SW 통계분석 > 변수 설정 편집에서 변수별 라벨, 척도(명목·서열·연속), 값 레이블(예: 1=남, 2=여), 결측값 코드(예: 99)를 입력합니다. 변수정의 탭에 직접 적어도 됩니다. 척도를 비워 두면 자동으로 판정합니다.
  3. 변수 만들기(선택): 메뉴 Stat4SW 통계분석 > 변수 계산에서 역문항 처리, 문항 합계·평균, z점수를 계산해 데이터 탭의 새 열로 추가합니다 (원본은 바뀌지 않습니다).
  4. 분석 실행: Stat4SW 통계분석 > 분석 창 열기에서 분석을 고르고, 왼쪽 변수 목록에서 변수를 골라 ▶ 보내기(또는 더블클릭)한 뒤 실행을 누릅니다. 어떤 분석을 쓸지 모르겠으면 분석 목록 아래의 도우미 열기를 누르세요. 변수를 체크하고 바로 추천받거나 질문에 답하면 추천 분석과 비모수 대안을 알려 주고, 변수를 넣은 채로 분석을 열어 줍니다.
  5. 결과 저장: 결과는 오른쪽에 쌓입니다. 시트로 내보내기를 누르면 결과 탭에 표 서식 그대로(차트는 그림으로) 저장됩니다. 분석 창을 닫으면 화면의 결과는 사라집니다. 결과 탭을 비우려면 Stat4SW 통계분석 > 결과 탭 지우기를 누르세요. 안내창에서 지울 것을 확인할 수 있고, 거리·유사도 분석이 만든 거리행렬·유사도행렬 탭은 탭째 삭제됩니다 (되돌릴 수 없으니 필요하면 먼저 복사하세요).

메뉴 구성

  • 분석 창 열기: 분석 실행 (가장 자주 씁니다)
  • 변수 설정 편집, 변수 계산, 결과 탭 지우기: 변수 준비와 결과 정리
  • 분석 선택 도우미 (넓게 보기): 어떤 분석을 쓸지 큰 화면에서 고릅니다 (분석 창 안의 도우미와 같은 기능)
  • 새 작업 시작 (데이터 모두 지우기): 새 분석을 시작할 때 데이터·변수정의 탭을 비웁니다 (지우기를 입력해야 진행, 끝나고 이전 결과도 지울지 묻습니다).
  • 설정·관리 하위 메뉴: 고급 분석 켜기/끄기, 시험 데이터 (시험 데이터는 고급 분석을 켠 뒤에 쓸 수 있습니다)
  • 고급 분석: 처음에는 자주 쓰는 기본 분석만 목록에 보입니다. 이원·반복측정 분산분석, 로지스틱·위계적 회귀, 요인분석, 생존분석처럼 변수와 가정이 많은 분석은 설정·관리 > 고급 분석 켜기/끄기를 누르면 나타납니다 (사용자마다 따로 기억되고, 다시 누르면 숨겨집니다).

연습해 보려면

  • Stat4SW 통계분석 > 예제 데이터 채우기: 60명 분량의 예제로 데이터·변수정의 탭을 채웁니다 (기존 내용을 덮어씁니다).
익명화된 데이터만 사용하세요. 이름, 연락처, 주민등록번호 같은 식별정보는 시트에 넣지 마세요. 이 도구는 별도의 개인정보 보호 처리를 하지 않습니다.

알아 둘 것

  • 복사한 시트에서 처음 메뉴를 실행하면 권한 승인 창이 뜹니다. "확인되지 않은 앱" 경고가 나오면 고급 > (프로젝트 이름)으로 이동을 눌러 승인하세요.
  • 사례는 최대 50,000건까지 분석합니다 (수천 건 규모를 기준으로 만들었고, 2만 건이 넘으면 느려질 수 있습니다). 넘으면 분석이 거부되고, 한도를 넘는 행에 입력하면 안내가 뜹니다.
  • PC 브라우저(Chrome 등)에서 사용하세요. 구글 시트 모바일 앱에서는 이 도구의 메뉴와 분석 창이 열리지 않습니다.
  • 이미 복사한 시트에는 이후 개선이 자동 반영되지 않습니다. 새 버전은 새 템플릿을 다시 복사해 데이터·변수정의 탭을 옮겨 쓰세요. 방법은 아래 새 버전으로 옮기기를 보세요. 현재 버전과 업데이트 링크는 메뉴 정보·저작권에 있습니다.

새 버전으로 옮기기

  1. 새 템플릿 링크로 사본 만들기를 해서 새 시트를 만듭니다.
  2. 예전 시트에서 데이터 탭 이름을 우클릭 > 복사 > 기존 스프레드시트로 새 시트에 보냅니다. 변수정의 탭도 같은 방법으로 보냅니다 (결과 탭이 필요하면 그것도).
  3. 새 시트에서 원래 있던 빈 데이터·변수정의 탭을 지우고, 새로 들어온 "…의 사본" 탭의 이름을 데이터, 변수정의로 바꿉니다.
  4. 새 시트에서 분석 창을 열어 변수 목록이 보이는지 확인합니다.
