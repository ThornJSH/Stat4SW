# Stat4SW 사용 안내

구글 시트 안에서 통계 분석을 하는 도구입니다. 데이터는 시트에 두고, 메뉴로 분석 창을 열어 변수를 고르면 결과가 표(와 차트)로 쌓입니다.
같은 내용이 시트의 메뉴 **Stat4SW 통계분석 > 사용 안내**에도 짧게 들어 있습니다.

> **이 시트는 당신의 개인 사본입니다.** 데이터는 이 시트에만 저장되고 외부로 보내지 않지만, 시트 링크를 다른 사람에게 공유하면 데이터도 함께 보입니다. 다른 사람의 시트에 편집자로 들어가 함께 작업하지 말고 각자 사본을 만들어 쓰세요 (처음 분석 창을 열 때 한 번 안내가 나옵니다).
>
> **익명화된 데이터만 사용하세요.** 이름, 연락처, 주민등록번호 같은 식별정보는 시트에 넣지 마세요. 이 도구는 별도의 개인정보 보호 처리를 하지 않습니다.

## 1. 처음 시작하기

1. 받은 템플릿 링크를 열고 **사본 만들기**를 누릅니다. 내 드라이브에 내 시트가 생기고, 분석 기능(스크립트)도 함께 복사됩니다.
2. 사본을 열면 메뉴 막대에 **Stat4SW 통계분석** 메뉴가 나타납니다. (보이지 않으면 새로고침하고 몇 초 기다리세요.)
3. 처음 메뉴를 누르면 **권한 승인** 창이 뜹니다. 내 시트를 읽고 쓰는 권한이므로 정상입니다.
   - "이 앱은 Google에서 확인하지 않았습니다"가 나오면 **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**을 누릅니다. 내가 복사한 내 스크립트라서 나오는 경고입니다.
4. 연습해 보려면 **Stat4SW 통계분석 > 예제 데이터 채우기**를 누르세요. 60명 분량의 예제(변수 27개)가 `데이터`·`변수정의` 탭에 들어갑니다 (**기존 내용을 덮어씁니다**). 변수마다 연습할 분석이 있습니다 (아래 "예제 데이터의 변수").

### 메뉴 한눈에 보기
시트 메뉴 **Stat4SW 통계분석**에는 다음이 있습니다.

| 메뉴 | 용도 |
| --- | --- |
| 분석 창 열기 | 분석을 고르고 실행하는 창 (가장 자주 씀) |
| 변수 설정 편집 / 변수 계산 | 변수의 라벨·척도·값 레이블 입력, 역문항·합계·평균·z점수로 새 변수 만들기 |
| 결과 탭 지우기 | `결과` 탭을 비우고, 거리·유사도 분석이 만든 행렬 탭(`거리행렬`, `유사도행렬`)도 함께 삭제 |
| 분석 선택 도우미 (넓게 보기) | 어떤 분석을 쓸지 큰 화면에서 고르는 도우미 (분석 창 안의 도우미와 같은 기능) |
| 새 작업 시작 (데이터 모두 지우기) | 새 분석을 시작할 때 `데이터`·`변수정의` 탭을 비움 (`지우기`를 입력해야 진행, 탭이 없으면 바로 만듦, 끝나고 이전 결과도 지울지 물음) |
| 예제 데이터 채우기 | 60명 분량의 연습용 예제로 `데이터`·`변수정의` 탭을 채움 (기존 내용이 지워지므로 연습용 시트에서) |
| 설정·관리 (하위 메뉴) | **고급 분석 켜기/끄기**, 시험 데이터 (시험 데이터는 고급 분석을 켠 뒤에만 실행됨) |
| 사용 안내 / 정보·저작권 | 도움말, 버전, 저작권·MIT 라이선스·계산 방법 출처·상표 고지 |

### 기본 분석과 고급 분석
처음에는 분석 목록에 **기본 분석 18개**(빈도분석, 기술통계, 정규성·등분산 검정, 이항 검정, t검정 3종, 일원 분산분석, 기본 비모수 검정, 상관분석, 교차분석, 선형 회귀, 신뢰도 분석, IPA)만 보입니다. 이원·반복측정 분산분석, 로지스틱·위계적 회귀, 조절·매개효과, 요인분석, 생존분석, 군집·거리, 검정력 같은 **고급 분석 19개**는 메뉴 **설정·관리 > 고급 분석 켜기/끄기**를 누르면 나타납니다 (다시 누르면 숨겨짐). 켜고 끄는 상태는 사용자마다 따로 기억되고, 열려 있는 분석 창은 닫았다가 다시 열거나 새로고침해야 반영됩니다. 암호는 없습니다 (화면을 단순하게 하려는 장치이고 보안 장치가 아닙니다). 선택 도우미가 고급 분석을 추천하면 열기 버튼 대신 켜는 방법을 알려 줍니다. 분석 안의 **세부 옵션**은 분석마다 자주 바꾸지 않는 옵션을 접어 둔 것이며 고급 분석과는 별개입니다.

## 2. 데이터 준비하기

### 예제 데이터 넣는 법
- **새 작업 시작 (데이터 모두 지우기)**(**Stat4SW 통계분석 > 새 작업 시작 (데이터 모두 지우기)**)는 새 분석을 시작할 때 `데이터`·`변수정의` 탭을 비우고 빈 템플릿으로 되돌립니다. 새 시트이거나 탭을 실수로 지웠다면 **없는 탭을 바로 만들어 줍니다.** 이미 내용이 있으면 지울 탭의 크기를 알려 주고, 이 도구에는 되돌리기가 없으니 필요하면 먼저 시트를 복사해 두라고 안내한 뒤 **`지우기`를 직접 입력해야** 진행합니다 (취소하거나 다르게 입력하면 아무것도 바뀌지 않음). 끝나면 이전 분석 결과(`결과` 탭, 거리·유사도 행렬 탭)도 지울지 따로 묻습니다. 고급 분석을 켜지 않아도 누구나 쓸 수 있습니다. 실수로 지웠다면 구글 시트의 **파일 > 버전 기록 > 버전 기록 보기**에서 이전 시점으로 되돌릴 수 있습니다 (시트 전체가 그 시점으로 돌아갑니다).
- 가장 쉬운 방법: 시트 메뉴 **Stat4SW 통계분석 > 예제 데이터 채우기**를 누르고 확인창에서 **예**를 선택합니다. `데이터`·`변수정의` 탭의 내용이 예제로 **바뀝니다** (기존 내용이 지워지므로 연습용 시트나 복사본에서 하세요). 메뉴가 안 보이거나 예전 예제(변수 5개)가 나오면 브라우저에서 시트를 새로고침(F5)한 뒤 다시 눌러 보세요.
- 파일로 가져오는 방법: 저장소의 `doc/예제데이터/예제_데이터.csv`, `예제_변수정의.csv`를 시트로 가져옵니다. 시트에서 **파일 > 가져오기 > 업로드**로 CSV를 고른 뒤 가져오기 위치를 "새 시트 삽입"으로 하고, 새 탭의 이름을 각각 `데이터`, `변수정의`로 바꿉니다 (기존 같은 이름의 탭은 먼저 지우거나 이름을 바꿔 두세요).

### 시험 데이터 (기법별 점검용)
새 분석을 확인할 데이터가 없을 때는 메뉴 **Stat4SW 통계분석 > 설정·관리 > 시험 데이터 (기법별 점검용)** 을 씁니다. 기법마다 **파이썬이 독립 계산한 시험 데이터**가 들어 있어서, 넣은 뒤 `시험안내` 탭의 순서를 따라 하면 **기대 결과(기준값)와 같은 숫자가 나오는지** 바로 확인할 수 있습니다.
1. 메뉴에서 시험 데이터를 고르고 **이 시험 데이터 넣기**를 누릅니다. `데이터`·`변수정의` 탭이 시험 데이터로 바뀌고 `시험안내` 탭이 생깁니다 (처음 넣을 때 원래 `데이터`·`변수정의` 탭은 `..._백업_날짜` 탭으로 복사되어 보관됩니다).
2. 분석 창을 열고 변수 목록의 새로고침을 누른 뒤, `시험안내`의 순서(분석, 변수, 옵션)대로 실행하고 결과의 숫자를 기대 결과와 비교합니다.
3. 끝나면 같은 메뉴의 **원래 데이터로 되돌리기**를 누릅니다 (시험 데이터를 지우고 백업 탭을 원래 이름으로 복원하며 `시험안내` 탭도 지웁니다). 다른 시험 데이터로 바꿔 넣을 때는 되돌리지 않아도 됩니다 (백업은 처음 것이 유지됩니다).
기본 예제(변수 27개)도 같은 메뉴에서 넣을 수 있고, 아래 "예제 데이터의 변수" 표대로 연습합니다.

### 예제 데이터의 변수
**Stat4SW 통계분석 > 예제 데이터 채우기**로 들어가는 변수들입니다. 값은 항상 같고, 실제 설문처럼 결측(빈 칸, 99, 999, 9999)이 섞여 있습니다.

| 변수 | 특징 | 연습할 분석 |
| --- | --- | --- |
| 성별, 집단, 지역 | 명목 (지역은 글자 값) | 교차분석, 집단 비교의 집단변수 |
| 연령, 근무연수 | 서로 거의 같이 움직임 | 상관분석, 회귀의 공선성(VIF) |
| 점수 | 정규에 가깝고 집단 분산이 비슷함 | t검정(Levene 유의하지 않음), 분산분석 |
| 만족도, 학력 | 서열 (값 레이블 있음) | 서열 척도 추천, 비모수 검정, 교차분석 |
| 사전점수, 사후점수 | 같은 사람의 두 측정, 집단 A < B < C 순으로 많이 오름 | 대응표본 t검정, Wilcoxon, 집단별 비교 |
| 월소득 | 오른쪽으로 크게 치우침 | 정규성 기각, 비모수·스피어만 추천 |
| 불안점수 | 성별마다 분산이 크게 다름 | 독립표본 t검정에서 "등분산을 가정하지 않음" 행이 굵게 |
| 스트레스 | 집단마다 분산이 다름 | 분산분석의 Levene 기각, Welch, Games-Howell |
| 문항1~5 | 같은 특성을 재는 5점 문항, **문항3·문항5는 역문항** | 변수 계산(역문항 → 합계·평균), 상관 |
| 성과점수 | 근무연수, 학력, 집단에 영향받음 | 선형 회귀 |
| 합격 | 성과점수가 높을수록 1 | 교차분석 (집단, 지역과) |
| 이직여부 | 0/1. 문항 평균이 낮고 근무연수가 짧을수록 1 (집단 차이는 약함) | 로지스틱 회귀 (변수 계산으로 만든 문항 평균과 함께) |
| 교육시간, 자기효능감, 동기수준, 직무성과 | 교육시간 → (자기효능감, 동기수준) → 직무성과. 자기효능감은 유의한 매개, 동기수준은 효과가 약함 | 매개효과 분석 (병렬 다중 매개) |
| 직무자율성, 직무몰입 | 근무연수가 직무몰입에 미치는 효과가 자율성이 높을수록 커지고 집단마다 기울기가 다름 | 조절효과 분석 (조절변수: 직무자율성 또는 집단) |

'문항3'과 '문항5'를 **변수 계산 > 역문항 처리**(범위 1~5)로 뒤집은 뒤 문항1·2·4와 함께 평균을 내 보세요.

### `데이터` 탭
- **1행은 변수명**, **2행부터 한 줄이 한 사례**입니다.
- 변수명은 겹치면 안 됩니다 (겹치면 첫 번째 열만 씁니다).
- 빈 칸은 결측으로 봅니다. 완전히 빈 행은 무시합니다.
- **사례는 최대 50,000건(행)까지** 분석할 수 있습니다. 넘으면 분석이 거부되고, 한도를 넘는 행에 입력하는 순간 화면 아래에 안내가 뜹니다 (입력 자체는 막을 수 없습니다). 데이터를 나누거나 표본을 추출해 줄이세요.
- 숫자로 분석할 변수(연속)에 글자가 섞여 있으면 그 칸을 결측으로 처리하고 경고를 보여 줍니다. 날짜는 숫자가 아닙니다.

### `변수정의` 탭 (선택이지만 권장)
변수마다 한 줄씩 적습니다. 비워 둔 칸은 자동 판정합니다.

**직접 입력하지 않고 메뉴 `Stat4SW 통계분석 > 변수 설정 편집`을 쓰면 편합니다.** `데이터` 탭 1행의 변수 목록에서 변수를 골라 라벨, 척도, 결측값 코드를 적고, 값 레이블은 데이터에 있는 값(과 사례 수)이 표로 나오므로 레이블만 채우면 됩니다 (`1=남, 2=여` 형식으로 저장됩니다). 연령, 점수 같은 **연속 척도 변수는 값 레이블을 쓰지 않아** 표가 나오지 않습니다 (1~5점 척도처럼 값마다 뜻이 있으면 척도를 서열이나 명목으로 바꾸세요). `정의 없는 변수 모두 추가`는 `변수정의` 탭에 아직 없는 변수의 이름을 한 번에 채웁니다. 저장한 뒤 분석 창이 열려 있으면 **새로고침**을 누르세요. 아래 표는 `변수정의` 탭을 직접 고칠 때의 형식입니다.

| 열 | 내용 | 예 |
| --- | --- | --- |
| 변수명 | `데이터` 탭 1행의 이름과 똑같이 (드롭다운에서 고르면 틀리지 않습니다. 목록에 없는 이름은 경고 표시가 납니다) | `성별` |
| 라벨 | 결과표에 보일 이름 | `성별` |
| 척도 | 드롭다운에서 고름: **명목**(순서 없는 범주), **서열**(순서 있는 범주), **연속**(숫자 크기가 의미 있음) | `명목` |
| 값 레이블 | `값=이름`을 쉼표·세미콜론·줄바꿈으로 구분 | `1=남, 2=여` |
| 결측값 코드 | 결측을 뜻하는 값. 여러 개면 쉼표로 | `99` 또는 `99, 999` |

- 척도를 비우면 모든 값이 숫자일 때 **연속**, 아니면 **명목**으로 자동 판정하고, 변수 목록에서 흐린 배지로 표시합니다.
- 척도는 분석 창에서 **어떤 변수를 어느 칸에 넣을 수 있는지**를 정합니다 (예: 집단변수 칸은 명목·서열만 받습니다).

### 변수 계산 (역문항, 합계·평균, z점수)
메뉴 **Stat4SW 통계분석 > 변수 계산**에서 새 변수를 만듭니다. 결과는 `데이터` 탭의 **맨 오른쪽에 새 열**로 쓰이고 `변수정의` 탭에도 등록됩니다 (원본 열은 바뀌지 않습니다). 쓰기 전에 **미리보기**로 열 위치와 값을 확인합니다.

| 계산 | 하는 일 | 입력 |
| --- | --- | --- |
| 역문항 처리 | 새 값 = 최솟값 + 최댓값 − 값 (1~5점이면 1↔5, 2↔4). 부정 문항을 다른 문항과 같은 방향으로 맞춥니다 | 변수(여러 개), 척도의 최솟값·최댓값, 새 변수 이름 접미사(기본 `_r`) |
| 합계·평균 | 여러 문항을 하나로 합칩니다 | 변수(2개 이상), 새 변수 이름, 최소 유효 문항 수 (기본: 모두 유효해야 계산) |
| z점수 | (값 − 평균) / 표준편차로 표준화합니다 | 변수(여러 개), 새 변수 이름 접미사(기본 `_z`) |

- 척도 범위는 **설문의 실제 범위**(예: 1~5점)를 직접 확인해 입력하세요. 칸에는 값 레이블이나 데이터에서 찾은 범위가 미리 채워지지만, 아무도 고르지 않은 값이 있으면 데이터만으로는 범위를 알 수 없습니다. 범위 밖의 값은 뒤집을 수 없어 결측으로 둡니다 (경고가 나옵니다).
- 합계·평균에서 응답하지 않은 문항이 있으면 합계는 사례마다 문항 수가 달라 비교하기 어렵습니다. 결측을 허용할 때는 **평균**을 쓰세요. 결측값 코드(예: 99)는 `변수정의`에 적어 두면 계산에서 빠집니다.
- 신뢰도나 척도 점수를 만들 때는 **역문항 처리를 먼저** 하고, 새로 생긴 열(예: `q3_r`)을 합계·평균에 넣으세요.
- 새 변수 이름이 이미 있으면 만들지 않습니다. 숫자가 아닌 값이 있는 변수와, 척도가 명목인 변수의 역코딩은 할 수 없습니다. 만든 열을 지우려면 `데이터` 탭에서 그 열과 `변수정의`의 해당 행을 직접 지우세요.
- 분석 창이 열려 있으면 **새로고침**을 눌러야 새 변수가 목록에 나옵니다.

## 3. 분석 창 사용법

메뉴 **Stat4SW 통계분석 > 분석 창 열기**를 누르면 세 칸짜리 창이 열립니다.

| 왼쪽 | 가운데 | 오른쪽 |
| --- | --- | --- |
| 변수 목록 (척도 배지, 결측 수) | 분석 종류(목적별로 묶여 있고 아래에 언제 쓰는지 한 줄 설명이 나옴), 역할 칸, 옵션(기본 + 접힌 고급), 실행 | 결과가 아래로 쌓입니다 |

1. 가운데에서 **분석**을 고릅니다. 어떤 분석을 써야 할지 모르겠으면 그 아래의 **"어떤 분석을 쓸지 모르겠어요? 도우미 열기"**를 누르세요 (아래 "분석 선택 도우미" 참고).
2. 왼쪽 변수를 체크하고 역할 칸의 **▶ 보내기**를 누르거나, 변수 이름을 **더블클릭**합니다. (같은 분석 안에서 다른 칸에 있던 변수는 그 칸에서 빠져 옮겨 갑니다. 집단변수처럼 "1개"라고 쓴 칸은 하나만 받습니다.)
3. 필요하면 **옵션**을 고릅니다 (사후검정, 차트 등). 자주 쓰지 않는 옵션(신뢰수준 등)은 **세부 옵션**에 접혀 있으니 누르면 펼쳐집니다. 옵션은 계정마다 기억됩니다.
4. **실행**을 누르면 오른쪽에 결과가 쌓입니다.
   - 결과마다 **삭제**, 위쪽에 **전체 지우기**가 있습니다.
   - 변수를 바꾼 뒤에는 왼쪽 위 **새로고침**을 누르세요.
5. **시트로 내보내기**(결과별) 또는 **전체를 시트로**를 누르면 `결과` 탭 맨 아래에 이어서 씁니다.
   - 표는 서식 그대로, 숫자는 숫자로 들어갑니다. 유의확률은 `.043`, `<.001` 같은 글자입니다.
   - 차트는 그림으로 들어갑니다. 그림은 시트에 나타나기까지 **몇 초~수십 초** 걸릴 수 있습니다.
   - **분석 창을 닫으면 화면의 결과는 사라집니다.** 남기려면 먼저 내보내세요.
   - `결과` 탭을 비우려면 메뉴 **Stat4SW 통계분석 > 결과 탭 지우기**를 누르세요. 지울 것을 안내하는 확인창이 뜨고, **예**를 누르면 `결과` 탭의 내용과 그림이 지워집니다. 거리·유사도 분석에서 "근접도 행렬을 새 탭에 저장"으로 만든 `거리행렬`·`유사도행렬` 탭(같은 이름이면 `_2`, `_3` …)은 **탭째 삭제되며 되돌릴 수 없으니** 필요하면 먼저 복사해 두세요. `데이터`·`변수정의` 탭과 직접 만든 다른 탭은 건드리지 않습니다.

### 분석 선택 도우미
분석 목록 아래의 **도우미 열기** 버튼, 또는 메뉴 **Stat4SW 통계분석 > 분석 선택 도우미 (넓게 보기)**(큰 화면)를 누르면 두 가지 방법으로 분석을 추천받습니다.
- **변수로 바로 추천**: 왼쪽 변수 목록에서 변수를 1~2개 체크하고 **체크한 변수로 바로 추천받기**를 누르면, 변수의 척도(명목·서열·연속)와 집단 수를 보고 추천합니다. 예를 들어 연속 변수 `점수`와 두 집단 변수 `성별`을 체크하면 독립표본 t검정을 추천하고, **이 분석 열기**를 누르면 변수가 알맞은 칸에 들어간 채로 열립니다.
- **질문에 답하기**: "무엇을 알고 싶나요?"(분포 확인, 집단 비교, 사전·사후, 기준값 비교, 관계, 영향 요인, 설문 신뢰도, 묶기·이상치, 처치 효과)에서 시작해 집단 수와 결과 변수의 종류를 고르면 추천 분석과 **비모수 대안**을 보여 줍니다.
- 표본이 30건 미만이면 평균 비교류 추천에 "정규성이 의심되면 비모수 대안을 보라"는 안내가 붙습니다. 정규성은 분석 결과의 **가정 점검**이 자동으로 판단해 알려 줍니다.
- 큰 화면에서는 왼쪽에서 변수를 체크해 바로 추천받거나 카드로 질문에 답하고, **분석 창에서 열기**를 누르면 분석 창이 그 분석을 고르고 변수를 채운 채 열립니다.
- 이 도구에 아직 없는 분석(예: 이항 검정, 편상관)은 "아직 지원하지 않음"으로 표시하고 쓸 수 있는 가까운 분석을 안내합니다.

## 4. 어떤 분석을 쓰나

| 분석 | 이럴 때 | 넣을 변수 | 주요 결과 |
| --- | --- | --- | --- |
| 빈도분석 | 값별 사례 수와 비율 | 아무 변수 | 빈도표 (옵션: 막대그래프) |
| 이항 검정 | 합격/불합격처럼 둘로 나뉜 변수의 성공 비율이 기준 비율과 다른가 | 변수(여러 개 가능) + 성공값, 검정 비율 | 성공·실패 빈도, 정확 유의확률(양측·단측), 정확·Wilson 신뢰구간 |
| 기술통계 | 평균, 표준편차 등 요약 | 숫자 변수 | 기술통계량 (옵션: 왜도·첨도, 히스토그램) |
| 정규성 검정 | 분포가 정규에 가까운가 | 숫자 변수 | Shapiro-Wilk(사례 3~5,000건), Jarque-Bera 통계량과 유의확률 |
| 등분산 검정 | 집단별 퍼짐이 같은가 | 종속(숫자) + 집단 | Levene 통계량, 유의확률 |
| 일표본 t검정 | 평균이 기준값과 다른가 | 숫자 변수 + 검정값 | t, 유의확률, 평균차이의 신뢰구간, 효과크기(d) |
| 독립표본 t검정 | 두 집단의 평균 비교 | 종속 + 집단(2개) | t, 유의확률, Levene, 신뢰구간, 효과크기(d, g) (옵션: 상자그림) |
| 대응표본 t검정 | 같은 대상의 두 측정 비교 | 변수1, 변수2 | t, 유의확률, 상관, 효과크기(d_z, g_z, d_av) |
| 일원 분산분석 | 세 집단 이상의 평균 비교 | 종속 + 집단 | F, 유의확률, 효과크기, Welch, 사후검정 (Tukey, Games-Howell, Bonferroni, Scheffé, LSD, Šidák, Dunnett) |
| 이원 분산분석 | 집단을 나누는 기준이 2가지(성별 × 프로그램)일 때 두 요인의 효과와 상호작용 | 종속 + 요인 1 + 요인 2 | 개체-간 효과 검정(F, 부분 η²), 단순 주효과, 사후검정, 상호작용 그림 |
| Mann-Whitney U 검정 | 두 집단 비교 (정규성이 아닐 때, 독립표본 t검정의 대안) | 종속 + 집단(2개) | 순위표, U, Z, 유의확률(점근·정확), 효과크기 r |
| Wilcoxon 부호순위 검정 | 대응표본 또는 기준값 비교 (대응표본·일표본 t검정의 대안) | 변수1, 변수2 / 변수 + 검정값 | 음·양·동순위 표, Z, 유의확률(점근·정확), 효과크기 r |
| 반복측정 분산분석 (집단변수는 선택) | 같은 사람을 3회 이상 측정한 값의 평균이 달라졌는가 (사전·중간·사후). 집단변수를 넣으면 집단에 따라 변화가 다른가(집단 × 측정)까지 | 측정 변수 3개 이상 (측정 순서대로; 집단변수가 있으면 2개 이상) + 집단변수(선택) | 구형성 검정, 교정한 F 검정, 부분 η², 쌍별 비교(Bonferroni), 평균 선 그림 (집단변수가 있으면 개체-간 검정, 단순 효과, 상호작용 그림) |
| Cochran Q 검정 | 같은 사람을 3회 이상 측정한 예/아니오 반응의 성공 비율이 달라졌는가 | 측정 변수 3개 이상 + 성공값 | 측정별 성공 빈도, Q, 유의확률, Kendall W, 쌍별 McNemar(Bonferroni), 그림 |
| Friedman 검정 | 같은 사람을 3회 이상 측정한 값(사전·중간·사후)이 달라졌는가 (순위 기준) | 측정 변수 3개 이상 (측정 순서대로) | 평균 순위, χ², 유의확률, Kendall W, 사후비교(Dunn–Bonferroni) |
| Kruskal-Wallis 검정 | 세 집단 이상 비교 (일원 분산분석의 대안) | 종속 + 집단 | 순위표, H, 유의확률, 효과크기 η², Dunn 사후검정 |
| 탐색적 요인분석 | 여러 문항이 몇 개의 묶음(요인)으로 나뉘는가 | 문항 변수 3개 이상 (숫자·서열) | KMO·Bartlett, 공통성, 설명된 총분산, 스크리 그림, 병렬분석, 회전된 요인 행렬(프로맥스는 패턴·구조 행렬과 요인 상관) (옵션: 추출 방법, 회전, 요인 수, 요인 점수 저장) |
| Kaplan–Meier 생존분석 (log-rank) | 사건(사망·재발·이탈 등)까지의 시간을 중도절단을 반영해 보고 집단을 비교 | 시간 + 사건 (+ 집단은 선택) | 처리 요약, 시점별 생존율(신뢰구간), 중앙값 등 백분위수, log-rank·Breslow·Tarone–Ware, 쌍별 비교, 생존곡선 |
| 검정력·표본 크기 계산 | 연구 전에 몇 명이 필요한가, 정해진 인원의 검정력은 (데이터 필요 없음) | 옵션만 입력 (검정 종류, 효과크기, 유의수준, 목표 검정력) | 필요한 표본 크기, 검정력, 효과크기별 표, 검정력 곡선, 탈락 감안 모집 인원 |
| IPA 중요도–수행도 분석 | 문항별 중요도와 만족도(수행도)를 비교해 무엇을 먼저 개선할지 | 중요도 문항들 + 수행도 문항들 (같은 순서로 짝지음) | 문항별 평균·격차·사분면, 기준선, 격차 검정, 4사분면 그림 |
| 평가자 일치도 (kappa) | 두 평가자(또는 두 번)의 범주 평가가 얼마나 일치하는가 | 평가자 변수 2개 이상 (평가자마다 열 하나) | 교차표, kappa, 신뢰구간, 가중 kappa, (3명 이상은 Fleiss kappa와 쌍별 kappa) |
| 급내상관 (ICC) | 평가자(또는 반복 측정)가 숫자 점수를 얼마나 일치하게 매겼는가 (검사-재검사 포함) | 평가자·측정 변수 2개 이상 | ICC 6유형(신뢰구간, F), 이원 분산분석표 |
| 신뢰도 분석 | 설문 문항들이 같은 특성을 일관되게 재는가 | 문항 변수 2개 이상 (숫자) | 크론바흐 α, 문항-전체 상관, 문항 제외 시 α (옵션: 신뢰구간, 문항 간 상관) |
| 서열 로지스틱 회귀 | 결과가 순서 있는 범주(5점 척도 한 문항 등)일 때 무엇이 더 높은 범주를 만드는가 | 종속(서열, 3~10가지) + 독립변수 | 모형 검정, 문턱값·B·Exp(B), 비례오즈 가정 점검(Brant) |
| 로지스틱 회귀 | 결과가 두 가지(예/아니오)일 때 무엇이 영향을 주나 | 종속(값 2가지) + 독립변수(숫자·범주) | 오즈비(Exp(B)), 모형 검정, Hosmer-Lemeshow, 분류표, ROC·AUC |
| 매개효과 분석 | X가 M을 거쳐 Y에 미치는 간접효과가 있는가 | 종속(Y), 독립(X), 매개(M, 1개 이상) + 공변량 | 경로 계수(a, b, c', c), 간접효과의 부트스트랩 신뢰구간, Sobel, 경로도 |
| 조절효과 분석 | X가 Y에 미치는 효과가 W에 따라 달라지는가 | 종속(Y), 독립(X), 조절(W) + 공변량 | 상호작용 검정(ΔR²), 단순기울기, Johnson-Neyman, 상호작용 그림 |
| 의사결정나무 | 어떤 변수·값으로 나누면 결과를 가장 잘 예측하는가, 규칙으로 보고 싶다 | 종속 + 예측변수(숫자·범주형) | 나무 그림과 규칙 표, 가지치기 곡선, 변수 중요도, 분류표 또는 R² (옵션: 예측값 저장) |
| k-평균 군집분석 | 비슷한 사례끼리 몇 개의 집단으로 묶을 수 있는가 | 숫자 변수 2개 이상, 군집 수 | 군집 중심, 군집별 사례 수, 군집 수 판단 보조(엘보·실루엣) (옵션: 군집 번호 저장) |
| 성향점수 매칭 | 처치를 받은 집단과 받지 않은 집단을 비슷하게 맞춘 뒤 처치 효과를 비교 | 처치(값 2가지), 공변량, (선택) 결과 변수 | 성향점수 모형, 균형 진단(SMD), 매칭 요약, 처치 효과(ATT) (옵션: 매칭ID·가중치 저장) |
| 거리·유사도 | 사례(또는 변수)가 서로 얼마나 다른가, 다변량 이상치는 없는가 | 숫자 변수 2개 이상 | 거리 행렬(앞 50×50), 요약, 마할라노비스 D²와 이상치 후보 (옵션: 새 탭에 저장) |
| McNemar 검정 | 같은 사람의 전·후 예/아니오 응답(예: 취업 여부)이 달라졌는가 | 변수1(전), 변수2(후) (값이 합쳐서 2가지) | 교차표, 정확·점근 유의확률, 비율 차이, 오즈비 |
| 상관분석 (편상관, 켄달) | 두 변수가 함께 움직이는가 (통제변수를 넣으면 그 영향을 뺀 상관, 서열·동순위가 많으면 켄달 타우-b) | 숫자 변수 2개 이상 (+ 통제변수 선택) | 상관계수, 유의확률, N (옵션: 신뢰구간, 산점도), 통제변수가 있으면 편상관과 통제 전·후 비교 |
| 교차분석 | 두 범주형 변수가 관련 있나 | 행 변수, 열 변수 | 교차표, 카이제곱, Fisher(2×2), 효과크기 |
| 선형 회귀 | 여러 변수로 결과를 설명 | 종속 + 독립변수 | R², 계수, 표준화 계수, VIF, 공선성 진단 |
| 위계적 회귀 | 통제변수를 먼저 넣고 핵심 변수가 설명력을 얼마나 더 높이는가 | 종속 + 1단계 독립변수 (+ 2~4단계 추가 독립변수) | 단계별 R², R² 변화량과 F 변화 검정, 단계별 계수 |

- **의사결정나무**는 변수 값에 따라 사례를 둘씩 나눠 가며 결과를 예측하는 **규칙 나무**를 만듭니다. 종속변수가 **연속(숫자 크기가 의미)이면 회귀 나무**, 합격/불합격 같은 범주이면 **분류 나무**입니다. 종속변수에 결과를, 예측변수에 숫자 변수와 범주형 변수를 나눠 넣습니다. 나무는 처음에 크게 키운 뒤 **교차검증**으로 가장 알맞은 크기로 가지를 칩니다(**가지치기 곡선**에서 선택한 크기가 표시됩니다). **나무 그림**의 각 상자는 사례 수(N)와 예측을 보여 주고 조건이 맞으면 왼쪽, 아니면 오른쪽입니다. **변수 중요도**는 어떤 변수가 나눔에 크게 기여했는지, **분류표**(또는 R²)는 예측이 얼마나 맞는지를 보여 줍니다. **훈련 자료를 다시 예측한 정확도는 낙관적**이므로 교차검증 정확도를 함께 보세요. 나무는 자료가 조금 바뀌어도 모양이 달라질 수 있어 규칙을 너무 정확히 믿지 말고 큰 흐름을 읽는 용도로 쓰세요. 시드가 같으면 항상 같은 결과이고, 최대 깊이나 최소 사례 수는 옵션에서 바꿀 수 있습니다.
- **k-평균 군집분석**은 숫자 변수들이 비슷한 사례끼리 **정해 둔 개수(k)의 군집**으로 묶습니다. 변수를 2개 이상 고르고 **군집 수**를 정합니다 (몇 개가 좋은지 모르면 `군집 수 판단 보조`의 군집 내 제곱합이 급격히 꺾이는 지점과 평균 실루엣이 큰 군집 수를 참고하되, 해석이 되는 개수로 정하세요). 단위가 다른 변수(연령과 소득 등)는 **표준화: z점수**(기본)로 두어야 소득처럼 큰 단위의 변수가 군집을 좌우하지 않습니다. 결과에서 **최종 군집 중심**(원래 단위)으로 각 군집의 특징을 읽고, **군집별 사례 수**가 한쪽으로 크게 쏠리지 않는지 봅니다. 변수별 F는 어떤 변수가 군집을 나누는 데 중요했는지 보는 참고이고 유의확률은 검정으로 해석하지 않습니다. 시드가 같으면 항상 같은 결과이고, 세부 옵션에서 바꿀 수 있습니다. 옵션으로 군집 번호를 데이터 탭에 저장하면 그 열로 집단 비교 분석(ANOVA, 교차분석 등)을 이어서 할 수 있습니다.
- **성향점수 매칭**은 관찰 연구(무작위 배정이 아닌 자료)에서 "프로그램에 참여한 사람과 안 한 사람"처럼 처치를 받은 집단과 받지 않은 집단이 **처음부터 다를 때** 그 차이를 줄여 효과를 비교하는 방법입니다. **처치 변수**(값 2가지, 큰 값이 처치), 처치 선택에 영향을 줄 **공변량**(숫자는 공변량, 범주형은 범주형 공변량 칸), 효과를 보고 싶은 **결과 변수**를 고릅니다. 먼저 공변량으로 처치 확률(성향점수)을 로지스틱 회귀로 구하고, 처치 사례마다 성향점수가 가장 가까운 대조 사례를 짝짓습니다(**캘리퍼**: 너무 먼 짝은 허용하지 않는 한계, 기본 0.2). 결과에서 **균형 진단**의 매칭 후 SMD가 모두 0.1 아래이면 두 집단이 비슷해진 것이고, 그러면 **처치 효과 추정**의 "매칭 후"(ATT)를 봅니다. 매칭 전 "단순 비교"는 집단 차이가 섞인 값입니다. 짝을 못 찾아 버린 처치가 많거나(공통 지지 부족) 균형이 안 맞으면 캘리퍼를 줄이거나 공변량을 바꿔 보세요. 관찰하지 못한 변수는 보정되지 않습니다. 옵션으로 성향점수·매칭ID·가중치를 데이터 탭에 저장해 다른 분석에 쓸 수 있습니다.
- **위계적 회귀**는 독립변수를 **단계(블록)로 나눠 차례로** 넣으면서, 단계마다 설명력(R²)이 **유의하게 늘었는지** 봅니다. 보통 1단계에 **통제변수**(성별, 연령 등 이미 알려진 영향)를, 2단계 이후에 **확인하려는 변수**를 넣어 "통제한 뒤에도 이 변수가 설명력을 더하는가"를 봅니다. 종속변수와 1단계 독립변수를 고르고, 2~4단계에 추가할 변수는 **앞 단계부터** 채우세요 (각 단계는 앞 단계 변수를 모두 포함합니다). **명목 변수는 더미로 자동 변환**되고(기준은 첫 범주) **서열·숫자 변수는 숫자 점수로** 들어갑니다. 5점 척도 같은 서열 변수를 점수로 쓰고 싶지 않고 범주로 보려면 변수 설정에서 척도를 명목으로 바꾸세요. 결과의 **모형 요약**에서 `R 제곱 변화량`은 그 단계에서 추가한 변수들이 더한 설명력이고, `유의확률 F 변화량`이 .05보다 작으면 **유의한 증가**입니다 (1단계 행은 모형 전체의 값). 개별 변수의 영향은 **계수** 표의 단계별 값(B, 베타, 유의확률)을 읽되, 보고할 때는 보통 마지막 단계의 값을 씁니다. 모든 단계의 변수 중 하나라도 값이 비어 있는 사례는 모든 단계에서 빠집니다. 공분산분석(ANCOVA)은 1단계에 공변량, 2단계에 집단(명목)을 넣으면 같은 모형으로 볼 수 있습니다.
- **이항 검정**은 "합격률이 50%와 다른가", "불량률이 기준 5%보다 작은가"처럼 **두 가지로 나뉘는 변수의 성공 비율**을 기준 비율과 비교합니다. 변수를 고르고 **성공으로 볼 값**(예: 1 또는 `합격`; 이 값이 아닌 값은 모두 실패)과 **검정 비율**(귀무가설의 성공 확률, 기본 0.5)을 적습니다. 검정 방향은 보통 양측이고, 자료를 보기 전에 방향을 정한 경우에만 단측을 씁니다. 정규 근사가 아니라 **정확한 이항 확률**이라 표본이 작아도 쓸 수 있고, 성공 비율의 신뢰구간(Clopper–Pearson, Wilson)도 함께 나옵니다. 세 가지 이상 범주의 비율 비교는 지원하지 않습니다.
- 일원 분산분석의 **사후검정**은 세부 옵션에서 고릅니다. 모든 쌍을 비교하려면 Tukey(기본 추천, 등분산)나 Games-Howell(분산이 다를 때)을 쓰고, **대조군 하나와 나머지를 각각 비교**하려면 **Dunnett**을 씁니다 (**Dunnett의 통제집단** 칸에 집단 값이나 값 레이블을 쓰고, 비우면 첫 집단이 통제집단입니다. 결과표에서 (J) 집단이 통제집단). LSD는 다중비교 보정이 없어 1종 오류가 커지므로 집단이 적고 전체 F가 유의할 때만 쓰세요. Šidák은 Bonferroni보다 약간 덜 보수적인 보정입니다.
- **이원 분산분석**은 집단을 나누는 기준이 **2가지**일 때(예: 성별 × 프로그램 참여) 쓰고, **두 요인 각각의 효과(주효과)와 두 요인의 조합 효과(상호작용)** 를 한 번에 검정합니다. 종속변수에 점수를, 요인 1(그림의 가로축)과 요인 2(그림의 선)에 범주 변수를 넣으세요 (두 요인 모두 **모든 조합에 사례가 있어야** 합니다). **먼저 상호작용을 보세요.** `개체-간 효과 검정`의 `요인 1 × 요인 2` 유의확률이 .05보다 작으면 한 요인의 효과가 다른 요인의 수준에 따라 달라진다는 뜻이라 주효과를 그대로 해석하면 오해하기 쉽습니다. 그때는 **상호작용 그림**(선이 평행하지 않고 벌어지거나 교차함)과 **단순 주효과**(예: "프로그램 참여군 안에서 성별 차이", 검정을 여러 번 하므로 유의수준을 나눠서 보세요)로 해석하세요. 상호작용이 유의하지 않으면 주효과를 해석하고, 수준이 3개 이상인 요인은 **사후검정**(어느 수준 사이가 다른지)을 봅니다. 부분 η²는 각 효과의 크기입니다. 셀마다 사례 수가 다른 **불균형 설계**에서는 **제곱합 유형**에 따라 주효과 결과가 달라지는데, 보통 **유형 III**을 쓰면 됩니다 (사례 수가 같으면 두 유형이 같습니다). Levene 검정이 유의하면 셀 사이 분산이 달라 결과를 조심해서 해석하세요 (셀 크기가 비슷하면 영향이 작습니다). 대조군이 있는 사전·사후 평가처럼 같은 사람을 반복 측정한 경우는 이원 분산분석이 아니라 (집단 × 시점) 혼합 설계 분산분석이 필요한데 다음 버전에서 반복측정 분석에 추가됩니다. 공분산분석(ANCOVA)은 위계적 회귀로 할 수 있습니다.
- **반복측정 분산분석(집단변수 선택)** 의 기본인 일원 반복측정은 **같은 사람을 3번 이상 측정**한 값의 **평균**이 달라졌는지 봅니다 (2번이면 대응표본 t검정). 사전·중간·사후처럼 **측정한 순서대로** 변수를 보내세요. 한 사람이 모든 측정에 값이 있어야 하며 비어 있는 사람은 통째로 빠집니다. 먼저 **구형성 검정(Mauchly)** 을 봅니다. 구형성은 "측정 사이 차이들의 변동이 비슷하다"는 가정이고, 유의확률이 .05 이상이면 가정이 성립해 **"구형성 가정" 행**을 읽습니다. .05 미만이면 가정이 깨진 것이라 자유도를 줄여 교정한 행 (ε가 .75 이하이면 **Greenhouse–Geisser**, 그보다 크면 **Huynh–Feldt**)을 읽으며, 읽을 행은 굵게 표시됩니다. F가 유의하면 평균이 측정에 따라 달라진 것이고, **쌍별 비교**에서 어느 두 측정 사이가 다른지(보정 유의확률 .05 미만에 *) 봅니다. 부분 η²는 효과의 크기, 일반화 η²는 연구 사이를 비교할 때 권장되는 값입니다. 정규성이 의심되면 순위로 비교하는 Friedman 검정을 함께 보세요. **집단변수 칸에 집단(예: 실험군·대조군)을 넣으면 "집단 × 측정" 혼합 설계 분산분석**이 됩니다 (측정은 2번 이상이면 되고 집단마다 사람 수가 달라도 됩니다). 이때 핵심은 **개체-내 효과 검정의 "측정 × 집단" 행**입니다: 유의하면 집단에 따라 시간에 따른 변화가 다르다는 뜻(예: 프로그램 효과)이라, 측정 주효과나 집단 주효과를 그대로 해석하지 말고 **상호작용 그림**(선이 평행하지 않음)과 **단순 효과**(각 집단 안에서 측정 효과, 각 측정에서 집단 효과; 검정을 여러 번 하므로 유의수준을 나눠서 보세요)로 해석하세요. 구형성 검정과 교정 행 선택(굵게 표시)은 일원 반복측정과 같은 방식이고, 집단 안에서 합친 공분산으로 계산합니다. **개체-간 효과 검정의 집단 행**은 측정 전체의 평균을 집단 사이에서 비교한 것입니다. 쌍별 비교는 집단 안에서 측정 쌍마다 보여 줍니다. 대조군이 있는 사전·사후 평가에서는 "측정 × 집단"이 프로그램 효과의 핵심 검정입니다 (측정이 2번이면 구형성 검정은 필요 없습니다).
- **Cochran Q 검정**은 같은 사람을 **3번 이상** 측정한 **예/아니오(0/1) 반응**(예: 3개월마다 취업 여부, 같은 문항 3개의 정답 여부)의 성공 비율이 달라졌는지 봅니다 (2번 측정이면 McNemar 검정). 측정마다 변수 한 열이고 사람이 행이며, **성공으로 볼 값**(예: 1)을 적으면 그 값이 아닌 응답은 모두 실패입니다. 유의하면 **쌍별 비교**(정확 McNemar, Bonferroni 보정)로 어느 측정 사이가 다른지 봅니다. 빈 칸이 있는 사람은 통째로 제외합니다. 모든 측정에서 응답이 같은 사람은 결과에 영향이 없고, 응답이 달라진 사람이 10명 미만이면 근사가 부정확할 수 있다는 경고가 나옵니다. 0/1 자료에 Friedman 검정을 해도 같은 Q가 나옵니다.
- **Friedman 검정**은 **같은 사람을 3번 이상 측정**한 값이 달라졌는지 순위로 봅니다 (대응표본의 확장이고, 2번 측정이면 Wilcoxon 부호순위 검정이나 대응표본 t검정). 사전·중간·사후처럼 **측정한 순서대로** 변수를 보내세요. 한 사람이 모든 측정에 값이 있어야 하며 비어 있는 사람은 통째로 빠집니다. 사람마다 값에 순위를 매겨 측정별 **평균 순위**를 구하고, 유의확률이 작으면(.05 미만) 어느 측정 이상이 다르다는 뜻이니 **사후비교**(어느 두 측정 사이가 다른지, 보정 유의확률 .05 미만에 *)를 봅니다. **Kendall W**는 0~1로 클수록 측정 사이의 변화가 일관됩니다. 0과 1로 코딩한 응답(예·아니오)에 쓰면 Cochran의 Q와 같은 값이 됩니다. 평균을 비교하는 분석은 일원 반복측정 분산분석을 쓰세요.
- **McNemar 검정**은 같은 사람을 두 번 잰 **예/아니오 응답이 바뀌었는지**(예: 프로그램 전·후 취업 여부) 봅니다. 변수1에 전, 변수2에 후를 넣습니다 (두 변수의 값이 합쳐서 0/1처럼 2가지여야 합니다). 검정에는 **값이 바뀐 쌍**(미취업→취업, 취업→미취업)만 쓰고, 안 바뀐 쌍은 영향을 주지 않습니다. 값이 바뀐 쌍이 25건 미만이면 **정확 유의확률**을 보세요. 비율 차이(후 − 전)와 오즈비(미취업→취업이 반대 방향보다 몇 배 많은지)로 변화의 크기도 읽습니다.
- **거리·유사도**는 사례(행) 또는 변수(열) 사이가 얼마나 다른지를 숫자로 보여 줍니다. 변수를 2개 이상 고르고 **측도**를 정합니다 (일반적으로 유클리드 거리, 단위가 다르면 **표준화: z점수**를 함께 고르세요 — 표준화하지 않으면 소득처럼 단위가 큰 변수가 거리를 지배한다는 경고가 나옵니다). 거리는 값이 클수록 다르고 유사도(코사인, 상관, Jaccard 등)는 클수록 비슷합니다. 결과 행렬은 화면에 **앞 50×50까지**만 보이고, 전체는 옵션 **근접도 행렬을 새 탭에 저장**(500개까지)으로 새 탭에 씁니다. **마할라노비스 이상치 점검**을 켜면 사례별 D²와 χ² 유의확률로 p < .001인 이상치 후보를 보여 주고, D²를 데이터 탭의 새 열로 저장할 수 있습니다. 후보는 바로 지우지 말고 입력 오류인지 다른 집단인지 먼저 확인하세요.
- **서열 로지스틱 회귀(비례오즈)** 는 결과가 **순서가 있는 범주**(예: 만족도 1~5점 한 문항, 상·중·하)일 때 어떤 변수가 **더 높은 범주**가 될 가능성을 높이는지 봅니다. 종속변수(값 3~10가지, 값이 클수록 높은 범주)에 결과를, 숫자 독립변수와 범주형 독립변수(더미로 자동 변환)에 나머지를 넣으세요. 결과에서 먼저 **모형 적합 정보**(유의하면 독립변수들이 함께 결과 범주를 설명), 다음에 **모수 추정값**을 봅니다. **B가 양수**이면 그 변수가 클수록 더 높은 범주가 될 가능성이 크고 **Exp(B)**는 변수가 1 늘 때 "더 높은 범주(누적)에 속할 오즈"가 몇 배가 되는지입니다(1이면 효과 없음, 범주형은 기준 범주 대비). **문턱값**은 범주 사이의 경계로 해석하지 않고 모형의 일부입니다. 이 모형은 한 변수의 효과가 모든 문턱값에서 같다는 **비례오즈 가정**을 하므로 **비례오즈 가정 점검(Brant)** 을 꼭 확인하세요: 유의확률이 .05 이상이면 가정이 성립하고, 유의하면 문턱값마다 계수가 달라 그 변수의 단일 Exp(B)를 그대로 믿기 어렵습니다(표본이 크면 사소한 차이에도 유의해지니 계수 차이의 크기도 보세요). 위반이면 범주를 합쳐 이분형 로지스틱 회귀를 함께 보는 방법이 있습니다. 범주별로 사례가 5건 미만이면 이웃 범주를 합치는 것을 고려하고, 여러 문항의 합계·평균처럼 거의 연속인 점수는 선형 회귀도 쓸 수 있습니다. 옵션으로 분류표와 예측 범주·범주별 확률의 데이터 탭 저장이 있습니다.
- **로지스틱 회귀**는 결과가 합격/불합격처럼 **값이 2가지**일 때 쓴다. 종속변수에 그 변수를, 숫자 독립변수와 범주형 독립변수(더미로 자동 변환)에 나머지를 넣는다. 기본은 **큰 값이 사건(1)**이고(`종속변수 코딩` 표에서 확인) 옵션으로 작은 값을 사건으로 바꿀 수 있다. **시트에서 0/1 열을 미리 만들 필요는 없다**: 종속변수를 보내면 분석 창 아래쪽에 값 목록이 나오고, **사건(1)으로 볼 값**을 직접 고르거나(3가지 이상인 변수도 됨, 예: 만족도 4·5점 = 사건) 숫자 변수는 **이 값 이상이면 사건**(예: 70점 이상)을 입력할 수 있다. 범주형 독립변수는 **기준 범주**를 목록에서 고른다. 결과에서 먼저 `모형 검정`(상수만 있는 모형보다 나은가), 다음에 `방정식의 변수`를 본다: `Exp(B)`(오즈비)는 독립변수가 1 늘 때(범주형은 기준 범주 대비) 사건의 오즈가 몇 배가 되는지이고 1이면 효과가 없다. `Hosmer-Lemeshow`는 유의확률이 **크면** 적합이 나쁘다는 증거가 없다는 뜻이다. `분류표`는 절단값(기본 .5)을 넘으면 사건으로 예측한 정확도이고, `AUC`는 사건과 비사건을 구분하는 능력(.5 무작위 ~ 1 완벽)이다. 어떤 변수가 결과를 거의 완벽히 가르면(완전 분리) 계수가 발산해 경고가 나오고 그 결과는 믿을 수 없으니 변수를 빼거나 범주를 합친다. 사건 수가 적은데 변수가 많으면(사건 10건당 변수 1개 미만) 경고가 나온다. 옵션 `예측확률·예측소속을 데이터 탭에 저장`을 켜면 확인창 뒤에 `데이터` 탭 맨 오른쪽에 새 열로 저장한다.
- **매개효과 분석**은 "X가 Y에 미치는 효과의 일부가 매개변수 M을 거치는가"를 봅니다. 종속(Y), 독립(X), 매개변수(M, 여러 개 가능)를 고르면 a 경로(X→M), b 경로(M→Y, X 통제)와 직접효과 c', 총효과 c를 계산하고 c = c' + 간접효과(a·b의 합)로 나눕니다. **간접효과의 유의성은 부트스트랩 신뢰구간**(기본 5,000회)이 0을 포함하지 않는지로 봅니다(굵게 표시한 행, 유의하면 `*`). 시드를 같게 두면 같은 결과가 나옵니다. Sobel 검정은 참고용이고 정규분포를 가정하므로 표본이 작으면 부트스트랩을 우선하세요. 통계적 매개 검정은 시간 순서와 이론적 근거가 있을 때만 의미가 있고 인과관계를 증명하지 않습니다. 직접효과가 유의하지 않다고 "완전 매개"라고 단정하지 마세요. 사례가 매우 많으면(대략 2만 건 이상) 계산 시간을 줄이려고 부트스트랩 횟수가 자동으로 줄어듭니다.
- **조절효과 분석**은 "X의 효과가 W에 따라 달라지는가"를 봅니다. 종속변수(Y), 독립변수(X, 숫자), 조절변수(W)를 한 칸에 하나씩 고르고 필요하면 공변량(숫자)을 더합니다. W의 **척도가 명목이면 범주형**(더미로 바꿔 범주마다 효과를 보여 줌), 연속·서열이면 숫자로 다룹니다. 핵심은 `상호작용 검정`의 유의확률입니다: 유의하면 조절효과가 있고, `조건부 효과`(W가 평균 −1SD, 평균, +1SD일 때 X의 효과)와 그림으로 어떻게 달라지는지 해석합니다. `Johnson-Neyman` 표는 W의 어느 구간에서 X의 효과가 유의한지 알려 줍니다. 옵션 `평균 중심화`(기본 켬)를 켜면 X와 연속형 W를 평균으로 중심화해 곱하므로 계수 해석이 쉬워지고 공선성이 줄어듭니다.
- **탐색적 요인분석(EFA)** 은 여러 문항이 **몇 개의 묶음(요인)** 으로 나뉘는지, 각 문항이 어느 요인에 속하는지 찾습니다 (설문의 구성 타당도 점검). 문항을 3개 이상 고르면 됩니다 (5점 척도 같은 서열 문항도 숫자 점수로 씁니다). 모든 문항에 응답한 사례만 쓰며, 사례 수는 문항 수의 **5배 이상(100건 이상이면 좋음)** 이어야 안정적입니다. 먼저 **KMO**(0.6 이상이면 요인분석에 쓸 만하고 0.5 미만은 부적합)와 **Bartlett 검정**(유의해야 함)으로 적합한지 보고, 공통성 표의 **MSA**가 0.5 미만인 문항은 빼는 것을 고려하세요. **요인 수**는 기본으로 고유값 1 이상(Kaiser)이지만 이 기준은 요인을 많게 잡는 경향이 있으니 **스크리 그림**에서 꺾이는 지점, **병렬분석**(같은 크기의 난수 자료보다 고유값이 큰 요인만 유지하는 방법, 결과의 "권하는 요인 수"), 해석이 되는지를 함께 보고 "요인 수" 칸에 직접 지정해도 됩니다. **추출 방법**은 기본 **주축분해**(문항의 공통 분산만 쓰는 요인분석)이고, **주성분**은 전체 분산을 요약하는 방법입니다. **회전**은 요인이 해석하기 쉬운 구조가 되도록 돌리는 것으로 기본은 **베리맥스**(요인끼리 상관이 없다고 보는 직각 회전)입니다. 설문의 하위 영역처럼 **요인끼리 상관이 있을 것 같으면 프로맥스**(사각 회전)를 고르세요: 해석에는 **패턴 행렬**(다른 요인의 영향을 뺀 문항별 기여)을 쓰고, **요인 상관 행렬**에서 요인 사이 상관이 .3 이상이면 사각 회전이 알맞습니다 (모두 .3 미만이면 베리맥스 결과와 비슷합니다). **구조 행렬**은 문항과 요인의 단순 상관입니다. 결과는 **회전된 요인 행렬**로 해석합니다: 문항은 가장 크게 적재된 요인별로 묶여 정렬되고 0.3 미만은 비워 보여 줍니다. 보통 적재값 **.4 이상**이면 그 요인에 속한다고 보고, **두 요인에 .32 이상 걸치는 문항(교차적재)** 이나 어디에도 크게 적재되지 않는 문항은 빼고 다시 분석해 보세요. 한 요인에 문항이 2개 미만이면 요인 수를 줄이세요. 요인마다 어떤 내용의 문항이 모였는지 보고 **이름을 붙인 뒤**, 요인별로 묶은 문항에 **신뢰도 분석**(크론바흐 α)을 이어서 하세요. 이 분석은 이론 없이 구조를 탐색하는 것이라 같은 자료로 확인했다고 말할 수 없고, 가설을 검증하려면 다른 자료로 확인적 요인분석(이 도구에는 없음)이 필요합니다. 옵션 **요인 점수를 데이터 탭에 저장**을 켜면 사례별 요인 점수(회귀 방법)가 `요인점수1`… 열로 저장되어 다른 분석(회귀, 집단 비교)에 쓸 수 있습니다. 다만 논문에서는 요인별 문항의 **평균·합계 점수**를 쓰는 경우가 더 흔하니 연구 관행을 따르세요.
- **Kaplan–Meier 생존분석**은 사건(사망, 재발, 이탈, 구매 등)이 **일어날 때까지의 시간**을 보는 분석입니다. 관찰이 끝났는데 사건이 아직 안 일어난 사례(**중도절단**)가 있어서 평균 같은 보통 방법을 쓸 수 없을 때 씁니다. **시간 변수**(사건 또는 관찰 종료까지의 시간, 0 이상)와 **사건 변수**(사건이 일어났는지)를 고르고, 사건 변수의 어떤 값이 사건인지를 **사건으로 볼 값**에 적습니다 (기본 1. 그 값이 아닌 값은 모두 중도절단입니다). 집단변수를 넣으면 집단별 곡선과 **log-rank 검정**(세 집단 이상이면 쌍별 비교도, Bonferroni 보정)이 나옵니다. 결과의 **중앙값**은 사례의 절반이 사건을 겪는 시점이고 곡선이 거기까지 내려가지 않으면 "도달하지 않음"입니다. 생존율을 볼 시점(예: 12, 24, 36)을 쉼표로 적으면 그 시점의 생존율과 신뢰구간이 나옵니다. **관찰이 끝난 사례도 반드시 데이터에 넣고 사건 변수로 구분**해야 합니다 (빼면 생존율이 낮게 나옵니다). 집단 사이 위험의 비가 시간에 따라 일정하다는 가정(비례위험)에서 log-rank의 검정력이 가장 높고, 곡선이 서로 교차하면 Breslow·Tarone–Ware 결과와 그림을 함께 보세요. Cox 회귀(위험비, 여러 변수 조정)와 경쟁위험, 시간에 따라 변하는 변수는 지원하지 않습니다.
- **검정력·표본 크기 계산**은 **연구를 시작하기 전에** 몇 명을 모집해야 하는지(또는 정해진 인원으로 효과를 찾아낼 수 있는지)를 계산합니다. **시트의 데이터가 필요 없어서** 분석 목록에서 `연구 설계` 묶음의 이 분석을 고르고 옵션만 채우면 됩니다 (데이터 탭이 없어도 실행됩니다). **검정**을 고르고(독립표본 t, 대응표본·일표본 t, 일원 분산분석, 상관, 두 비율, 선형 회귀), **구하려는 값**(필요한 표본 크기 / 검정력 / 탐지 가능한 효과크기)을 고릅니다. 핵심 입력은 **효과크기**(d, f, r, f²: 평균 차이를 표준편차로 나눈 값 등)로, 선행연구의 값이나 "이 정도 차이는 의미 있다"고 볼 최소한의 차이로 정하세요. 모르면 비워 두면 Cohen의 관행(작음·중간·큼)의 "중간" 효과로 계산하고, 결과의 **효과크기별 표**에서 작은·중간·큰 효과일 때 필요한 인원을 같이 봅니다. 유의수준(보통 .05)과 목표 검정력(보통 .80, 효과가 실제로 있을 때 찾아낼 확률)을 정하고, 두 비율 비교는 두 비율을 직접 입력하세요. 필요한 표본 크기는 "목표 검정력 이상이 되는 가장 작은 인원"이고 두 집단 비교는 **집단당** 인원, 상관·회귀는 **총** 인원입니다. 세부 옵션의 **예상 탈락률**을 넣으면 탈락을 감안해 더 모집할 인원이 나옵니다 (프로그램 평가처럼 사후 조사에서 빠지는 사람이 생길 때). 결과의 곡선은 인원이 늘면 검정력이 어떻게 오르는지 보여 줍니다. 이미 수집한 자료의 "사후 검정력"은 p값과 일대일로 대응해 새 정보가 없어서 계산하지 않습니다. 상관은 근사식이라 G*Power의 정확법과 1명 안팎 다를 수 있고, 반복측정·혼합 설계·다층 설계의 표본 크기는 지원하지 않습니다 (R이나 G*Power의 시뮬레이션을 쓰세요).
- **IPA(중요도–수행도 분석)** 는 같은 문항들에 대해 **얼마나 중요한지(중요도)** 와 **얼마나 잘 되고 있는지(수행도, 만족도)** 를 각각 물은 설문에서, 무엇을 먼저 개선할지 4사분면으로 보여 줍니다. **중요도 문항 칸에는 중요도 문항들을, 수행도 문항 칸에는 만족도 문항들을 같은 개수, 같은 순서로** 보내세요 (첫째 문항끼리, 둘째 문항끼리 짝지어집니다). 결과의 **집중 개선**(중요한데 만족이 낮음) 문항에 자원을 먼저 투입하고, **현상 유지**는 지금 수준을 지키며, **과잉 투자**(덜 중요한데 만족이 높음)는 줄일 여지를 보고, **낮은 우선순위**는 나중으로 미룹니다. 십자 **기준선**은 기본이 문항 평균들의 평균이고, 옵션에서 중앙값이나 직접 지정한 값(예: 척도 중간값 3)으로 바꾸거나, 세부 옵션의 **기준선 이동**으로 계산된 값에서 조금씩 올리고 내릴 수 있습니다. 기준선을 어디에 두느냐에 따라 사분면이 달라지므로 **보고서에 어떤 기준선(방식과 이동량)을 썼는지 적어야** 하고, 결과표의 ★ 경계 표시는 기준선에서 0.1점 이내라 기준선을 조금만 옮겨도 사분면이 바뀔 수 있는 문항입니다. 중요도와 수행도는 **같은 척도(예: 1~5점)** 여야 합니다. 상관으로 구하는 "도출 중요도"와 집단별 IPA는 지원하지 않습니다.
- **평가자 일치도(kappa)** 는 두 사람이 같은 대상에 **범주(있음/없음, 상/중/하)** 를 매긴 것이 얼마나 일치하는지 봅니다. 평가자마다 변수 한 열을 두고 대상(사례)이 행이 되게 하세요. 단순 일치율은 우연히 맞는 부분이 섞여 있어서, **kappa**는 우연 일치를 뺀 일치도(1이 완전 일치, 0이 우연 수준)입니다. 해석 기준(Landis & Koch)은 0.2 이하 매우 낮음, 0.2~0.4 낮음, 0.4~0.6 보통, 0.6~0.8 높음, 0.8 초과 거의 완벽이고 신뢰구간 하한도 같이 보세요. 평가 범주에 **순서가 있으면(5점 척도 등)** 옵션에서 **이차 가중**(가장 흔함) 또는 선형 가중을 골라 가까운 범주끼리의 불일치를 덜 벌점 주세요. 한쪽 범주에 평가가 몰려 있으면 일치율은 높은데 kappa가 낮게 나오는 "kappa 역설"이 생기니 일치율도 같이 보고하세요. 평가자가 **3명 이상**이면 자동으로 **Fleiss kappa**(전체 일치도)와 범주별 kappa, **평가자 쌍별 kappa 행렬**을 보여 줍니다 (쌍별 값이 낮은 평가자를 찾을 때 쓰세요).
- **급내상관(ICC)** 은 평가자(또는 같은 사람을 여러 번 잰 측정)의 **숫자 점수**가 얼마나 일치하는지 봅니다. 평가자(측정)마다 변수 한 열, 대상이 행입니다. 1에 가까울수록 대상 사이의 차이가 평가자 사이의 차이보다 훨씬 커서 일치도가 높다는 뜻입니다. **유형 고르기**: 보통 단일 측정값을 보고 (굵게 표시), 평가자가 더 큰 집단에서 뽑힌 표본이고 점수 자체의 일치가 중요하면 **ICC(2,1)(절대 일치도)**, 평가자가 정해져 있고 순서·상대 비교만 중요하면 **ICC(3,1)(일관성)**, 서로 다른 평가자가 대상마다 달랐다면 ICC(1,1)입니다. 실제 측정에 여러 평가자의 평균을 쓰는 경우에만 평균 측정 값을 봅니다. 두 값이 크게 다르면(ICC(2,1) ≪ ICC(3,1)) 평가자마다 점수 수준이 달라 **평가자 편향**이 있다는 신호입니다. 해석 기준(Koo & Li): 0.5 미만 낮음, 0.5~0.75 보통, 0.75~0.9 좋음, 0.9 초과 매우 좋음이고, 추정값보다 **신뢰구간 하한**으로 판단하는 것이 권장됩니다. 유의확률은 "ICC = 0" 검정이라 크기와 신뢰구간이 더 중요합니다. 대상이 30건 이상이면 신뢰구간이 안정적입니다. 검사-재검사 신뢰도는 같은 사람의 1차, 2차 점수를 두 변수로 넣어 ICC를 구합니다.
- **신뢰도 분석**은 한 척도를 이루는 문항들(예: 문항1~5)을 모두 선택합니다. 모든 문항에 응답한 사례만 씁니다(목록별 결측 제거). **역문항(부정 문항)은 먼저 `Stat4SW 통계분석 > 변수 계산 > 역문항 처리`로 뒤집은 새 열을 만들어 그 열을 선택**하세요. 안 그러면 α가 음수이거나 낮게 나옵니다(경고가 나옵니다). 결과의 "문항-전체 통계량"에서 굵게 표시된 문항은 빼면 α가 올라가는 문항입니다. α는 .70 이상을 흔히 기준으로 삼지만 문항 수와 연구 목적에 따라 다르고, .95를 넘으면 문항이 중복일 수 있습니다.
- **효과크기**: t검정 결과 아래의 `효과크기` 표(옵션 `효과크기`, 기본 켬)는 평균 차이가 **얼마나 큰지**를 표준화한 값입니다. 유의확률은 차이가 우연인지를, 효과크기는 차이의 크기를 알려 주므로 둘 다 보고하세요. Cohen's d는 평균 차이를 표준편차로 나눈 값이고, **Hedges' g**는 표본이 작을 때의 편향을 줄인 값입니다. 신뢰구간(비중심 t로 구한 정확한 구간)이 0을 포함하면 차이가 없다는 가능성을 배제하기 어렵습니다. 크기(참고)는 0.2 작음, 0.5 중간, 0.8 큼이라는 Cohen의 관행이며 절대적인 기준은 아닙니다. 대응표본은 **d_z**(차이의 표준편차 기준)와 **d_av**(두 측정 표준편차의 평균 기준, 다른 연구와 비교하기 좋음)를 함께 보여 줍니다. 방향은 평균차이와 같습니다 (집단1 − 집단2, 변수1 − 변수2).
- 독립표본 t검정 결과에서는 Levene 유의확률을 보고 읽을 행이 **굵게** 표시됩니다. Levene 유의확률이 .05 이상이면 "등분산을 가정함" 행, .05 미만이면 "등분산을 가정하지 않음"(Welch) 행입니다.
- 독립표본 t검정과 Mann-Whitney U 검정은 집단이 **정확히 2개**여야 합니다. 3개 이상이면 일원 분산분석이나 Kruskal-Wallis 검정을 쓰세요.
- **켄달 타우-b**: 상관분석의 옵션 `켄달 타우-b 순위상관`을 켜면 피어슨·스피어만과 같은 형식의 행렬이 하나 더 나옵니다. 5점 척도처럼 **같은 값이 많거나 표본이 작은** 서열 자료에서 스피어만의 대안으로 쓰고, 동순위를 보정한 값입니다 (보통 스피어만보다 절댓값이 작습니다). 동순위가 없고 사례가 33건 이하이면 정확 분포로, 그 밖에는 정규 근사로 유의확률을 구합니다. 통제변수(편상관)와는 함께 쓸 수 없습니다.
- **편상관**: 상관분석의 **통제변수** 칸에 변수(예: 연령)를 넣으면 그 변수의 영향을 뺀 상관(편상관)을 봅니다. 두 변수가 서로 관련돼 보이는 것이 사실은 둘 다 통제변수와 관련돼서일 수 있기 때문입니다. 결과의 **"통제 전 → 통제 후 비교" 표**에서 상관이 0에 가까워지면 통제변수가 관계를 대부분 설명한 것이고, 그대로면 통제변수와 무관한 관계, 부호가 바뀌거나 커지면 억제 효과입니다. 유의확률의 자유도는 N − 2 − 통제변수 수입니다. 스피어만을 고르면 모든 변수를 순위로 바꾼 뒤 편상관을 구합니다. 결측은 분석 변수와 통제변수가 모두 있는 사례만 쓰는 목록별 제거이고, 통제변수는 숫자·서열 변수만 쓸 수 있습니다 (범주형은 위계적 회귀에서 더미로 통제하세요). 옵션 산점도는 통제 후 잔차끼리의 산점도(부분회귀 그림)이고, 통제변수끼리 거의 같은 정보이면 계산할 수 없으니 하나만 넣으세요. 편상관은 인과를 뜻하지 않습니다.
- **가정 점검**: t검정, 일원 분산분석, 상관분석(피어슨)에는 옵션 `가정 점검`(기본 켬)이 있습니다. 정규성(집단별, 대응표본은 차이값)과 등분산을 점검해 결과 아래에 `가정 점검` 표와 `▶ 추천` 문구를 보여 줍니다. 정규성이 기각되면 Mann-Whitney U, Wilcoxon, Kruskal-Wallis, 스피어만 같은 비모수 대안을, 분산만 다르면 Welch 결과를 보라고 권합니다. 추천은 판단을 돕는 안내일 뿐 분석 결과를 바꾸지 않습니다. 표본이 100건 이상이면 사소한 이탈에도 정규성이 기각되므로 왜도·첨도가 크지 않으면(|왜도| < 2, |첨도| < 7) 그대로 써도 된다고 안내합니다.
- 비모수 검정은 값의 크기가 아니라 **순위**로 비교하므로 정규분포를 가정하지 않고 이상치에 강합니다. 정규성이 의심되거나 표본이 작거나 서열 척도(예: 5점 척도)일 때 씁니다. 순위가 같은 값(동순위)이 많으면 정확 유의확률은 나오지 않고 점근 유의확률만 나옵니다.
- Wilcoxon 부호순위 검정은 두 값이 같은 쌍(차이가 0)을 순위에서 뺍니다. 표의 Z가 양수이면 변수1이 더 큰 쪽(또는 검정값보다 큰 쪽)이 우세합니다.
- 선형 회귀에서 명목·서열 변수는 **범주형 독립변수** 칸에 넣으면 더미 변수로 자동 변환됩니다 (기준 범주는 첫 범주, 옵션으로 마지막 범주).
- 결측은 분석마다 다릅니다: 기술통계·상관분석은 변수(쌍)별로, 그 밖의 분석은 필요한 변수가 모두 있는 사례만 씁니다. 결과표 아래 각주에 적혀 있습니다.

## 5. 문제가 생겼을 때

| 증상 | 확인할 것 |
| --- | --- |
| "1행에 변수명을 입력하고…" | `데이터` 탭 1행에 변수명이 있는지, 2행부터 데이터가 있는지 |
| 변수 목록이 비어 있다 / 옛 데이터가 보인다 | 왼쪽 위 **새로고침**을 누르세요 |
| 변수가 흐리게 보이고 체크가 안 된다 | 그 분석이 받지 않는 척도입니다. `변수정의` 탭에서 척도를 바꾸거나 다른 변수를 고르세요 |
| "숫자가 아닌 값이 있어…" | 그 변수에 글자가 섞여 있습니다. 결측을 뜻하는 글자(예: `.`, `NA`)는 `변수정의`의 결측값 코드에 적으세요 |
| "집단이 N개입니다…" | 집단변수의 집단 수가 그 분석과 맞지 않습니다 (독립표본 t검정은 2개) |
| "범주가 너무 많습니다" | 집단·범주형 변수에 범주가 너무 많습니다 (ANOVA 20개, 교차분석 30개, 회귀 10개까지) |
| "완전 공선성" | 회귀의 독립변수 하나가 다른 변수들의 합·복사본입니다. 그 변수를 빼세요 |
| 그림이 시트에 안 보인다 | 몇 초~수십 초 기다려 보세요 |
| "예기치 않은 오류가 발생했습니다" | 선택한 변수·옵션·데이터를 확인하세요. 계속되면 그 메시지를 전달해 주세요 (원인은 시트의 `확장 프로그램 > Apps Script > 실행` 기록에 남습니다) |
| "사례가 N건 있습니다. 이 도구는 최대 50000건까지…" | `데이터` 탭의 사례가 한도를 넘었습니다. 데이터를 나누거나 표본을 추출해 50,000행 이하로 줄이세요 |
| 빈도분석에서 "빈도표를 만들지 않았습니다" | 고유한 값이 500개를 넘는 변수(보통 연속형)입니다. 기술통계(히스토그램)를 쓰세요 |
| 느리다 | 사례가 2만 건을 넘거나, 집단이 많은 Games-Howell 사후검정은 오래 걸릴 수 있습니다 |
| SPSS와 값이 조금 다르다 | 소수점 반올림, 결측 처리(쌍별/목록별), 히스토그램 구간, 상자그림의 사분위수 계산 방식 차이일 수 있습니다 |

## 6. 새 버전으로 옮기기와 문제 알리기
- 이미 복사한 시트에는 새 버전이 **자동으로 적용되지 않습니다.** 현재 버전과 새 버전을 보는 링크는 메뉴 **정보·저작권**에 있습니다.
- **옮기는 방법**: ① 새 템플릿 링크로 사본 만들기 ② 예전 시트의 `데이터`·`변수정의` 탭(필요하면 결과 탭도)을 탭 이름 우클릭 **복사 > 기존 스프레드시트**로 새 시트에 보내기 ③ 새 시트의 빈 `데이터`·`변수정의` 탭을 지우고 "…의 사본" 탭의 이름을 `데이터`, `변수정의`로 바꾸기 ④ 분석 창을 열어 변수 목록 확인. 시트 기본 기능만 쓰는 방법입니다 (권한이 더 필요하지 않음).
- **문제를 알릴 때**: 메뉴 **정보·저작권**의 **진단 정보 복사**를 눌러 나온 내용(버전, 고급 분석 켜짐 여부, 탭 크기; 데이터 값·변수 이름·시트 제목은 들어 있지 않음)을 붙여 넣고, 어떤 분석에서 어떤 오류 문구가 나왔는지 함께 적어 주세요.
- **PC 브라우저에서 사용하세요.** 구글 시트 모바일 앱에서는 이 도구의 메뉴와 분석 창이 열리지 않습니다.

## 7. 알아 둘 한계

- 사례가 **수천 건** 규모를 기준으로 만들었고, **최대 50,000건**까지 분석합니다 (2만 건이 넘으면 느려질 수 있습니다).
- 지원하는 분석은 위 표의 것뿐입니다 (확인적 요인분석·구조방정식, 혼합효과모형, 생존분석 등은 없습니다). 정규성 검정은 Shapiro-Wilk와 Jarque-Bera이고, Jarque-Bera는 표본이 작으면(대략 30 미만) 정확도가 떨어지므로 작은 표본에서는 Shapiro-Wilk를 보세요. 표본이 큰데(대략 100 이상) 정규성이 기각되면 왜도·첨도와 히스토그램도 함께 보세요.
- 소수점 자릿수와 표 서식은 고정입니다 (통계량 3자리, 퍼센트 1자리, 유의확률 `.043`).
- 차트는 시트에 그림으로만 들어가며 시트에서 고칠 수 없습니다.
- 이미 복사한 시트에는 이후 개선이 **자동으로 반영되지 않습니다.** 메뉴 **Stat4SW 통계분석 > 정보**에서 내 시트의 버전을 확인하고, 새 템플릿을 다시 복사한 뒤 `데이터`·`변수정의` 탭 내용을 옮겨 붙이세요.
