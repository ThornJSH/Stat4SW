# 결과 객체와 렌더러 설계

모든 분석은 **결과 객체**를 반환하고, `Render.js`의 `renderResultHtml(result)`가 이를 HTML로 바꾼다.
결과 객체는 숫자를 원본 그대로 담고(반올림하지 않음), 표시 형식은 열 정의의 `format`이 정한다.
그래서 같은 객체로 HTML 표시, 시트 내보내기, APA 스타일 렌더러를 모두 만들 수 있다.

## 형식

```js
{
  analysis: 'frequencies',          // 분석 종류 키
  title: '빈도분석',                  // 결과 상단 제목
  blocks: [ /* 표 또는 문단 */ ],
  warnings: ['...']                 // 사용자에게 보일 경고 (결측 제외 건수 등)
}
```

### 블록

```js
// 표
{
  type: 'table',
  caption: '성별',                   // 표 제목
  columns: [
    { key: 'value', label: '값',   align: 'left' },
    { key: 'freq',  label: '빈도', format: { type: 'int' } },
    { key: 'pct',   label: '퍼센트', format: { type: 'fixed', digits: 1 } }
  ],
  rows: [
    { value: '남', freq: 30, pct: 50 },
    { _kind: 'total', value: '합계', freq: 60, pct: 100 }   // _kind: 'total' | 'subtotal'
  ],
  notes: ['값 레이블이 있으면 레이블로 표시']                  // 표 아래 각주
}

// 문단
{ type: 'text', text: '...' }

// 차트 (SVG로 그린다. 시트로는 PNG 그림으로 넣는다: 분석 창이 SVG를 PNG로 바꿔 서버로 보낸다)
{ type: 'chart', kind: 'bar' | 'histogram' | 'scatter' | 'box', caption: '...', /* kind별 자료: 아래 참고 */ }
```

### 열 형식 `format`

| type | 설명 | 예 |
| --- | --- | --- |
| `text` (기본) | 그대로 출력, 왼쪽 정렬 | 변수명 |
| `int` | 정수 | 빈도, N |
| `fixed` | 소수점 `digits`자리 고정 | 평균 3.250 |
| `trim` | 소수점 `digits`자리까지 반올림 후 불필요한 0 제거 | 최솟값 20, 2.5 |
| `pvalue` | `<.001`, `.043` 형식 (통계 보고 관행) | p값 |

- `null`, `undefined`, 빈 문자열은 빈 칸, 계산할 수 없는 값(NaN, Infinity)은 `.`로 표시한다
- 숫자 열은 오른쪽 정렬이 기본이고 `align`으로 바꿀 수 있다
- 한 표 안에서 행마다 형식이 다르면(상관 행렬의 상관계수·유의확률·N 행 등) 행에 `_fmt: { type: 'pvalue' }`처럼 쓴다. 이 행의 숫자 셀은 열 형식 대신 `_fmt`로 표시된다
- 행의 `_kind`: `total`, `subtotal`(위쪽 선), `group`(한 묶음의 첫 행, 얇은 위쪽 선)
- 행의 `_bold: true`: 그 행을 굵게 표시한다 (화면은 `tr.strong`, 시트 내보내기는 굵은 글씨). 예: 독립표본 t검정에서 Levene 결과로 읽을 행

### 차트 블록의 자료

| kind | 자료 |
| --- | --- |
| `bar` | `labels`, `values`(빈도), `xLabel`, `yLabel` |
| `histogram` | `bins`(`{lo, hi, count}`), `n`, `mean`, `sd` — 정규곡선은 평균·표준편차로 그린다 |
| `scatter` | `points`(`[x, y]`), `n`, `line`(`{slope, intercept}`), `r`, `xLabel`, `yLabel` |
| `box` | `groups`(`{label, n, q1, median, q3, lo, hi, outliers, extremes}`), `yLabel` |

차트 블록은 `Charts.js`의 `barChartBlock`, `histogramBlock`, `scatterBlock`, `boxplotBlock`으로 만들고, `Render.js`가 `renderChartHtml`로 SVG를 만든다.

## 설계 원칙

- 분석 함수는 `(dataset, request) → 결과 객체`인 순수 함수다. 시트나 HTML을 직접 만지지 않는다
- 사용자 입력 오류(변수 없음, 숫자가 아닌 변수 등)는 `Error`의 메시지로 던지고, 메시지는 그대로 화면에 표시된다
- 분석 종류 추가는 `Stats_*.js`에 함수를 만들고 `Api.js`의 분석 목록(`ANALYSES_`)과 `client.html`의 역할 칸 정의에 등록하는 것으로 끝나야 한다
